# Wyrmgate IAM

Wyrmgate IAM is an enterprise identity governance and administration platform under active development.

This site contains curated public documentation only. It is a published view, not the authoritative engineering or requirements repository.

## Current public scope

The public documentation baseline currently covers project positioning and documentation policy. Product guides, deployment guidance, API references, and customer-facing operational content will be added only after they are ready for external consumption.

## Documentation authority

Authoritative implementation-facing architecture and engineering documentation remains in the private `wyrmgate/iam` repository. Controlled business, software, architecture, security, integration, and traceability specifications remain in the formal specification package.

Public documentation must never expose secrets, private credential material, internal-only security procedures, customer data, provider credentials, or non-public architecture details merely because those materials exist in the source repository.
