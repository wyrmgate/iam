# Engineering Toolchain Baseline

## Status

Sprint 1B working baseline.

This document fixes the initial executable toolchain for Wyrmgate IAM. Changes to major runtime/build versions should be intentional and reviewed because they affect developer setup, CI, containers, support policy, and release artifacts.

## Server

- Java 25 LTS
- Spring Boot 4.1.x
- Apache Maven 3.9.x
- PostgreSQL as the target relational database
- Flyway for every schema change
- Spring JDBC as the initial persistence integration foundation
- Spring Boot Actuator for health/operational endpoints
- springdoc-openapi for OpenAPI publication
- JUnit 5 / Spring Boot Test
- ArchUnit for architecture-boundary tests as bounded-context implementation begins

The server remains a modular monolith. Package and module dependencies must preserve the documented direction: domain -> application/use-case -> ports/repositories -> infrastructure/adapters -> API composition, without domain code depending on infrastructure or API code.

## Console

- Node.js 24 LTS
- React 19.2.x
- TypeScript 7.0.x
- Vite 8.1.x
- npm initially, using the npm version supplied with the pinned Node LTS runtime

The console consumes backend-derived authorization and typed API contracts. It must not become an authorization decision engine and must not introduce permanent mock business state.

## Package namespace

New Java code uses `io.wyrmgate.iam`.

Legacy package names are migration inputs, not the namespace of the new Wyrmgate product repository.

## Version policy

- Pin runtime major versions in repository metadata.
- Prefer supported LTS runtimes for Java and Node.js.
- Pin security-sensitive/build plugins to reviewed versions.
- Maven Wrapper and frontend dependency lockfiles become mandatory once dependency installation is generated in the local-development bootstrap.
- Upgrades must pass unit, architecture, integration, migration, frontend build, and security CI gates once those gates exist.

## Deferred to Sprint 2+

- reproducible frontend dependency lockfile generated by npm
- Maven Wrapper bootstrap files
- Docker-based local PostgreSQL and Valkey
- local mail sink
- full frontend lint/test configuration
- generated typed OpenAPI client
- CI cache and dependency verification configuration
