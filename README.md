# Wyrmgate IAM

Private monorepo for the Wyrmgate Identity and Access Management platform.

This repository is currently in the platform-foundation and architecture phase. Application code, deployment assets, infrastructure-as-code, tests, and internal engineering documentation will be introduced incrementally through reviewed pull requests.

## Status

Pre-release / active development.

## Repository policy

- `main` is the long-lived integration branch.
- Changes should arrive through short-lived branches and pull requests.
- Secrets and private key material must never be committed.
- No open-source license has been selected for this product at this stage.
